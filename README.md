## Project files
- `dist/index.html` is the site page.
- `dist/images/` contains the cake and dessert photos used by the page.
- `.openai/hosting.json` identifies the existing Sites project.

## Preview locally
Open this folder in Codex. To run a local static preview, serve the `dist` directory with any static file server, for example:

```sh
python3 -m http.server 8000 --directory dist
```

Then open `http://localhost:8000`. No build step is required.
